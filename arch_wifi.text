  #tty with Nvidia driver
  
  had the same problem once, all TTYs except for the one where SDDM loaded went missing. 
  I fixed it by adding "nomodeset" to my kernel parameters.

I'm pretty sure it was something to do with my Nvidia GPU so if you use AMD or Intel graphics, this may not work for you.

To add "nomodeset" temporarily, press e at the GRUB boot menu, append nomodeset to the line starting with linux, 
and press Ctrl+X or F10 to boot. To make it permanent, edit /etc/default/grub, update GRUB, and reboot

Open your terminal once the system is running.Type 
sudo nano /etc/default/grub and press Enter.
Find the line that says GRUB_CMDLINE_LINUX_DEFAULT or GRUB_CMDLINE_LINUX.Add nomodeset
 inside the quotation marks on that line (next to text like quiet splash).
 Save the file by pressing Ctrl+O, 
hit Enter, then exit using Ctrl+X.
